HOW TO RUN
----------
1. Place all files in the same folder.
2. Open a terminal in that folder.
3. Run:  python YOURNAME_TPXXXXXX.py

If the four .txt files are deleted, the program recreates them on the next
run and reseeds the default Admin, Staff and Customer accounts below, so the
system can always be entered and demonstrated.

FEATURES
--------
Admin
  - Log in
  - Create administrative staff accounts
  - View all staff and customer details at once
  - Search staff and customers by ID or email
  - Generate any customer's statement of account
  - Edit staff details, change own password

Administrative Staff
  - Register a new customer from their registration form
  - Account number is autogenerated in sequence (10001, 10002, ...)
  - A default password is issued and shown to the staff member
  - Account type is Savings or Current
  - Edit customer details, but not the account number or name
  - Generate a customer's statement of account
  - View and search customers

Customer
  - Log in with account number and password
  - Change password
  - Deposit - balance updated in the data file
  - Withdraw - refused if it would breach the minimum balance
  - View own account details
  - Print own statement of account for a chosen period

MINIMUM BALANCE
---------------
  Savings  RS 1000.00
  Current  RS 1500.00
A refused withdrawal tells the customer the largest amount they may take
instead, rather than simply failing.

DEMONSTRATING THE MINIMUM BALANCE RULE
---------------------------------------
  Log in as 10003 - a Savings account holding RS 3000.00
  Try to withdraw RS 2500.00   ->  refused, RS 500 would remain
  Then withdraw RS 2000.00     ->  accepted, leaves exactly
                                   the RS 1000.00 minimum

STATEMENT OF ACCOUNT
---------------------
A start and an end date are entered in YYYY-MM-DD form. The report lists
every transaction in that period and ends with TOTAL DEPOSITS, TOTAL
WITHDRAWALS, NET MOVEMENT and CLOSING BALANCE.

MODULES USED
------------
os and datetime only, as permitted by the brief. No global variables are
used; constants are returned by functions instead.
